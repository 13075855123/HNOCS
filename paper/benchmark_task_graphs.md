# 实验 Benchmark 任务图详解

## 读图说明

- `T1 → T2` 表示 **T1 算完后，数据发给 T2，T2 才能开始算**
- `→ GB` 表示算完把结果发回 GlobalBuffer
- CSVs 中 `1, -2, 20000, 160, 2:0, 8:0` 表示 task 1 的 `peId=-2`（动态分配），`computeTime=20µs`，`dataSize=160B`，后继是 T2 和 T8
- 所有 peId = -2，GB 在运行时根据 PE 当前温度选冷 PE

---

## 1. GEMM（矩阵乘法分块）

### 物理含义

大矩阵 C = A × B。把 A 切成 4 块，B 切成 4 块，4 对小块**同时算**。

### 任务图（精确对照 CSV）

```
  T1(Split) ─── 切成 4 块
   │
   ├──→ T2(Block0) ──→ T6(Reduce0) ──┐
   ├──→ T3(Block1) ──→ T7(Reduce1) ──┤
   ├──→ T4(Block2) ──→ T8(Reduce2) ──┤
   └──→ T5(Block3) ──→ T9(Reduce3) ──┤
                                        ▼
                                    T10(Gather) → GB
```

**T1** 发给 4 个 Block 节点 → 4 路并行计算 → 4 路并行 Reduce → 汇聚到 T10 发回 GB

| 任务 | 计算量 | 后继 |
|------|--------|------|
| T1(Split) | 15µs | T2,T3,T4,T5 |
| T2-T5(Block 0-3) | 50µs 各 | T6-T9 对应 |
| T6-T9(Reduce 0-3) | 30µs 各 | T10 |
| T10(Gather) | 20µs | GB |

**关键路径**：15 + 50 + 30 + 20 = 115µs。最大并行度 4。

## 2. MPEG-4（视频解码器）

### 物理含义

视频解码流水线：GB 预加载 SDRAM 数据 → VOP 解析码流 → 变长解码 → 图像还原+运动补偿并行 → 汇聚光栅化 → 存入帧缓存/显示缓存输出。音频处理与视频**并行**。

SDRAM 预加载由 T0（GB 注入标记）完成，等效于 GB→PE0 的数据注入。

### 任务图（精确对照 CSV）

```
  T0(GB:SDRAM预加载) ──→ T1(VOP:输入解析,PE0)
                           │
                     ┌─────┼─────┐
                     ▼     ▼     ▼
              T2(VLD,PE1) T8(ADSP,PE2) T11(PCI,PE3)
             变长解码      音频处理      外设接口
               │             │            │
          ┌────┤             ▼            ▼
          ▼    ▼            GB           GB
    T3(IDCT,PE4) T4(MC,PE5)
     图像还原    运动补偿
          │         │
          ▼         ▼
    T5(RC,PE6)──→T6(RAST,PE7)←─┘
     游程解码     光栅化(汇聚点)
                    │
          ┌─────────┼─────────┐
          ▼         ▼         ▼
    T7(MED,PE8) T9(SRAM1,PE10) T10(SRAM2,PE11)
     运动估计     帧缓存        显示缓存
          │         │           │
          └─────────┴─────┬─────┘
                          ▼
                         GB
```

**关键特征**：
- T0(GB) 在 t=0 注入数据到 T1，SDRAM 预加载等效于 GB→PE
- T1→T2→...→T6 是串行主干（视频解码流水线）
- T1 同时分叉出三条并行路径：T2(视频)、T8(音频)、T11(外设)
- T6 是 RAST 汇聚点，之后分叉 3 路→GB
- 最大并行度 3（T1 的三个后继同时启动；T6 的三个后继同时启动）

| 任务 | 名称 | 计算量 | 前驱(谁的数据它需要等) | 后继(算完发给谁) |
|------|------|--------|---------------------|------------------|
| T1 | VOP 输入解析 | 20µs | T9 | T2, T8, T12 |
| T2 | VLD 变长解码 | 25µs | T1 | T3, T4 |
| T3 | IDCT 图像还原 | 35µs | T2 | T5 |
| T4 | MC 运动补偿 | 30µs | T2 | T6 |
| T5 | RC 游程解码 | 30µs | T3 | T6 |
| T6 | RAST 光栅化 | 35µs | T4, T5 | T7, T9, T10 |
| T7 | MED 运动估计 | 20µs | T6 | GB |
| T8 | ADSP 音频处理 | 25µs | T1 | GB |
| T9 | SRAM1 帧缓存 | 15µs | T6 | GB |
| T10 | SRAM2 显示缓存 | 15µs | T6 | GB |
| T11 | PCI 外设 | 20µs | T1 | GB |

注：T0 为 GB 注入标记（`peId=-1`），SDRAM 预加载并入 GB 注入。

**关键路径**：T0→T1→T2→T3→T5→T6→T7 = GB注入 + 20+25+35+30+35+20 = 165µs（不计 GB 注入的 10ns）

## 3. VOPD（视频对象平面解码器）

### 物理含义

这是 MPEG-4 的前身，专注于视频对象（非整帧）的解码。依赖链更长，适合展示温度感知在长串行链上的效果。

### 任务图（精确对照 CSV）

```
  T1(VOP:输入)
   │
   ├──→ T2(VLD:变长解码)
   │       │
   │       ▼
   │     T3(IDCT:图像还原)
   │       │
   │       ├──→ T4(MC:运动补偿)
   │       │       │
   │       │       ▼
   │       │     T5(RC:游程解码)
   │       │       │
   │       │       ▼
   │       │     T6(MED:运动估计)
   │       │       │
   │       │       ▼
   │       │     T7(RAST:光栅化)
   │       │       │
   │       │       ├──→ T8(ADSP:音频) → GB
   │       │       ├──→ T9(SDRAM:内存) → GB
   │       │       └──→ T10(SRAM1:帧缓存) → GB
   │       │
   │       └──→ T12(AUX:辅助) → GB
   │
   └──→ T11(VOP重排) → GB
```

**关键特征**：
- **最长串行链**：T1→T2→T3→T4→T5→T6→T7→T10，7 级串行
- T3 分叉成 T4（继续流水线）和 T12（辅助路径，并行结束）
- T11 与主线并行（T1 同时启动）
- T7 分叉成 3 路（T8 ADSP、T9 SDRAM、T10 SRAM1），全部→GB

| 任务 | 名称 | 计算量 | 后继 |
|------|------|--------|------|
| T1 | VOP 输入解析 | 25µs | T2, T11 |
| T2 | VLD 变长解码 | 30µs | T3 |
| T3 | IDCT 图像还原 | 30µs | T4, T12 |
| T4 | MC 运动补偿 | 30µs | T5 |
| T5 | RC 游程解码 | 30µs | T6 |
| T6 | MED 运动估计 | 30µs | T7 |
| T7 | RAST 光栅化 | 30µs | T8, T9, T10 |
| T8 | ADSP 音频处理 | 30µs | GB |
| T9 | SDRAM 内存 | 30µs | GB |
| T10 | SRAM1 帧缓存 | 25µs | GB |
| T11 | VOP 重排 | 20µs | GB |
| T12 | AUX 辅助同步 | 20µs | GB |

**关键路径**：T1→T2→T3→T4→T5→T6→T7→T10 = 25+30×7 = 235µs（取最长的那条 T10 结束）

## 四个 Benchmark 对比

| | GEMM | MPEG-4 | VOPD |
|---|---|---|---|
| Task 数 | 10 PE | 11 PE + 1 GB | 12 PE |
| 依赖类型 | fork-join | fork-join | 流水线+分叉 |
| 最大并行度 | 4 | 3（T1→音频/视频/外设；T6→MED/帧缓存/显示缓存） | 4（T7→音频/内存/帧缓存 + T12辅助） |
| 最长串行链 | 4 级 | 6 级（T1→T2→T3→T5→T6→T7） | 7 级 |
| 关键路径 | 115µs | 165µs | 235µs |
| 特点 | **并行度最高**，计算密集 | **GB 预加载 + fork-join**，NoC 论文高频引用 | **串行链最长**，温度累积效果最明显 |
