# Thermal RC Auxiliary Results

This folder consolidates the final ThermalRC-LS and ThermalOnly-RC-LS result directories.

Current ACP paper note: these are auxiliary/archival comparison results, not the two main method-level baseline methods. The main baseline methods are `Thermal-SA-TAS` and `CommAware-Heuristic`.

Contents:

- `thermal-only-rc-ls-v1-seed42/`: final ThermalOnly-RC-LS seed 42 run.
- `thermal-rc-ls-v1-seed42/`: final ThermalRC-LS seed 42 run.
- `thermal-rc-ls-v1-seed43/`: final ThermalRC-LS seed 43 run.
- `comparison_all_methods_seed42.csv`: consolidated comparison table for seed 42.
- `comparison_all_methods_seed42.json`: JSON version of the same comparison table.

Smoke-test directories were intentionally not included.
The protected B-2 GA result directories are not copied or modified here.
