# Figure 1 Source and Metadata

## Title

Simulation-in-the-loop thermal-aware task remapping framework for ONoC.

## Caption

Figure 1. Overview of the simulation-in-the-loop thermal-aware task remapping framework. A genetic algorithm generates candidate task-to-PE mappings, which are evaluated by a full-system OMNeT++ ONoC model. Thermal, performance, communication, balance, and energy metrics are converted into a baseline-normalized composite cost that drives selection for the next generation.
